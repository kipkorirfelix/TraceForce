TraceForce

Windows Activity & Event Intelligence Platform

TraceForce is a Windows monitoring and event intelligence platform built with C# and .NET 8. It collects Windows system events, tracks process activity, detects application crashes, and correlates related events into meaningful activities.

The goal is to turn raw Windows Event Log data into structured information that can support system monitoring, troubleshooting, auditing, and diagnostics.

Product: TraceForce

Features
Windows Event Collection — monitors Application, System, and Security event logs.
Process Tracking — tracks process IDs, parent processes, applications, users, and activity.
Crash Detection — identifies application crash events.
Crash Correlation — connects application crashes with Windows Error Reporting events.
Activity Correlation — groups related low-level events into meaningful activities.
Audit Monitoring — provides visibility into Windows auditing activity.
Local Web API — exposes a local HTTP interface for monitoring and integration.
Database Persistence — stores normalized events and correlated activities for later analysis.
